# Nightmare Launcher — Downloads

**Status:** ainda não há versão pública aprovada. A build intermediária está em validação do jogo e do instalador.

Quando uma versão passar nos testes, ela aparecerá em [Releases](https://github.com/vitinhugrau85-web/nightmare-launcher-downloads/releases), com instalador, SHA-256 e limitações conhecidas.
